# Scan Station

A home 3D-scanning setup. It turns iPhone photos into textured 3D models on a
Windows laptop, using COLMAP + OpenMVS (open source), with RealityScan as a
quality benchmark.

**Status:** Phase 2 setup. Nothing runs yet. This README will say what works
once it has been tested.

See [CLAUDE.md](CLAUDE.md) for the rules and decisions behind the project.
